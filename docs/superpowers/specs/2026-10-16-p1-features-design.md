# Design: P1 features after the first device test

Date: 2026-10-16 · Status: approved (user: "lanjutkan fitur yang belum") · Scope: PRD §10.1 P1, §11 Tahap 1 P1, Tahap 2 P1 (dead projects), Tahap 3 P1.

1. **Scan comparison.** `ScanStats` grows into a per-root snapshot (totals, categories, top 100 folders). `scan()` loads the previous snapshot before walking and returns `ScanResult.diff: Option<ScanDiff>` (since, Δbytes, Δfiles, Δ per category, folders with the largest |Δ|). UI: one sentence under the headline ("Bertambah 8,2 GB sejak 9 Okt, terutama dari …"); the scan target rows show "Terakhir dipindai …".
2. **Estimate before starting.** `eta::RateHistory` keeps the last five rates per operation (scan bytes/s, clean items/s, dedupe bytes/s) in `rates.json`; `estimate(kind, amount)` uses the median and `round_human`. Shown on the scan target row and in the Clean/Dedupe preview dialogs. Recorded after every real run.
3. **Notification on completion.** `tauri-plugin-notification`; fired when a scan, clean or dedupe run took ≥ 10 s. Setting `notify_when_done` (default on) in Settings.
4. **Dedupe P1.** Minimum size selectable in the UI (1 KB … 1 MB). Developer profile gets "replace with hardlink": the duplicate goes to the Trash through safety as usual, then `std::fs::hard_link(keep, duplicate_path)` restores the path with no extra space; failures (other volume, FS without hardlinks) are reported per group.
5. **Dead development projects.** `cleaner/projects.rs` finds project roots (package.json, Cargo.toml, pyproject.toml, go.mod, pubspec.yaml, build.gradle, pom.xml) under the home folder (bounded walk), derives the expected artefact folders from the ecosystem and declared frameworks, checks `.gitignore` and `git ls-files` (never suggest tracked folders), computes the project's last activity from its non-artefact files, and proposes a rebuild command. Green when ignored, untracked and stale ≥ 30 days; yellow when ignored and untracked but active. Replaces the generic `node-modules-stale` rule. UI: a "Proyek development" section in Bersih grouped per project.
